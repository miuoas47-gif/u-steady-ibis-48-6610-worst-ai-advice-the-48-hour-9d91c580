One line of the worst AI advice, in a confident assistant voice: a program that writes a single tight, concrete, hilariously bad tip about squealing brakes to `entry.txt` in the output directory. The line is 140 characters or fewer, deterministic, and runs with no arguments.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written; it defaults to `/output`.
